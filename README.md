# Recipe Sharing App

A simple Recipe Sharing App built using React, Express, and SQLite, designed for local usage. The app allows users to perform CRUD operations on recipes and mark recipes as favorites.

## Features

  - Add, view, edit, and delete recipes
  - Mark recipes as favorites and view them in a dedicated "Favorites" tab
  - Search recipes by title or ingredients
  - Lightweight and designed for local usage

## Tech Stack

**Frontend**
  - React
  - React Router for navigation
  - Axios for API requests

**Backend**
  - Express.js
  - SQLite for database management
